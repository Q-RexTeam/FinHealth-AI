# Từ điển Dữ liệu (Data Dictionary)

| Tên biến / Chỉ tiêu | Kiểu dữ liệu | Mô tả chi tiết | Công thức / Nguồn gốc |
| :--- | :--- | :--- | :--- |
| `company_name` | String | Tên doanh nghiệp | Dữ liệu niêm yết chính thức |
| `ticker` | String | Mã cổ phiếu (Mã chứng khoán) | HOSE / HNX / UPCoM |
| `financial_health_score` | Float | Điểm số sức khỏe tài chính tổng hợp | Chấm điểm chuẩn hóa (Thang điểm 100) |
| `risk_probability` | Float | Xác suất gặp rủi ro tài chính trong 12 tháng tới | Dự báo từ mô hình Machine Learning |

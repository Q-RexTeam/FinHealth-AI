# Phương pháp luận và Hướng dẫn kỹ thuật (Methodology)

1. **Tiền xử lý dữ liệu:** Làm sạch dữ liệu BCTC, xử lý giá trị khuyết thiếu và chuẩn hóa các chỉ số tài chính theo 5 nhóm tiêu chí (Thanh toán, Đòn bẩy, Sinh lời, Dòng tiền, Hiệu quả hoạt động).
2. **Mô hình Machine Learning:** Sử dụng các thuật toán phân lớp (XGBoost, Random Forest, LightGBM) để dự báo khả năng suy giảm tài chính.
3. **Khả năng giải thích (XAI):** Tích hợp SHAP Values để minh bạch hóa nguyên nhân dẫn đến kết quả cảnh báo rủi ro.
